# ⚡ Electric Vehicle Dashboard (Power BI)

This project showcases two interactive dashboards built in Power BI using a dataset of 478 electric vehicle models. It highlights key metrics such as battery capacity, range, efficiency, drivetrain distribution, and fast-charging capabilities.

## 📊 Dashboards

### 1. EV Overview Dashboard
- Total models, brands, average range, battery, efficiency
- Top 10 brands by range
- Drivetrain distribution
- Scatter plot: battery vs range
- Table: top 10 models by range

### 2. Charging & Technical Dashboard
- Fast-charging power by brand
- Range by segment
- Drivetrain vs car body type
- Efficiency vs range scatter
- Matrix: brand-wise averages

## DAX Measures
Over 15 DAX measures used for KPIs, filtering, and calculations. See [`DAX_Measures.txt`](DAX_Measures.txt) for full list.

## Power Query Transformations
Data cleaned and transformed using Power Query with no custom columns. See [`PowerQuery_Steps.txt`](PowerQuery_Steps.txt) for full steps.
